# Wordle - CS 2640 Final Project
## Group Members: Tyler Carrasco, Tiffany Dinh, Kendan Phan, Angela Salcido

## Purpose
This project is based on the popular online word guessing game, “Wordle,” using MIPS assembly. Its purpose is to stimulate the brain and allow users to engage in daily entertainment.

## How to Use
The program gives the user six attempts to correctly guess a randomly generated five-letter word. The user will input different words and the program will output whether or not each letter is in the correct place, and if the letter is used in the word. When the six attempts are up, the user loses.

## Features
* Users are prompted with a main menu to start the game or exit the program
* A random word is randomly picked and targeted as the correct word
* The user is limited to six attempts to guess correctly
* When users enter a 5-letter word, the program outputs one of the following for each letter:
- Correct position and correct letter
- Wrong position and correct letter
- Wrong position and wrong letter
* Replay menu when the correct word is guessed or all attempts are used
* Sound effects
